# PVRadar

- [PVRadar](https://pvradar.pages.dev)

PVRadarは，特定条件に合致するGitHubリポジトリおよびセキュリティアドバイザリを集約・表示するサービスです．主にセキュリティリサーチャーやOSSのバグハンター向けに設計されています．

### 収集条件

- `SECURITY.md` が有効，または `GitHub Security Advisory` が有効であること
- リポジトリのスター数が `1,000` 以上であること
- いずれかの言語で記述されていること (対応言語は順次追加予定): `["Python", "Rust", "Go", "JavaScript"]`

## 更新頻度

- データ収集は毎週月曜 `3:00` JST に実行されます．
- 大量のリポジトリデータを処理するため，GitHubのサーバーに過度な負荷をかけないよう，意図的にリクエスト間隔を設けています．そのため，データ収集の完了までに数十分から数時間程度かかる場合があります．


## Tech Info

- 開発期間: 1.5ヶ月
- サーバーサイド: Rust (Actix-Web)
- クライアントサイド: Plain Typescript
- データベース: Postgres (SQLx)
